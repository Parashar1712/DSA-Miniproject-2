# 📖 Project Overview

**DSA Mini Project 2** is a console-based student management system developed in C++. The project demonstrates how fundamental **Data Structures and Algorithms** can be combined to solve a practical real-world problem.

The application manages two major types of information:

- 👨‍🎓 **Student Records** using a **Singly Linked List**
- 🎫 **Support Queries** using a **Queue**

The system provides functionality for adding, displaying, searching, deleting and sorting student records, along with submitting, viewing and resolving support queries.

> 💡 **Project Goal:**  
> Transform theoretical DSA concepts into a simple, practical and interactive application.

# ✨ Key Features

## 👨‍🎓 Student Record Management

The student management module allows users to:

- ➕ Add new student records
- 📋 Display all students
- 🔍 Search students by roll number
- 🗑️ Delete student records
- 📈 Sort students by marks
- 🔤 Sort students alphabetically by name

Each student contains:

```text
┌─────────────────────────┐
│       STUDENT NODE      │
├─────────────────────────┤
│ Roll Number             │
│ Name                    │
│ Course                  │
│ Marks                   │
│ Next Node Pointer       │
└─────────────────────────┘
